# Web Application

1. Create a Firebase project.
2. Enable Authentication -> Email/Password.
3. Enable Firestore Database.
4. Create a Web App in Firebase.
5. Copy its configuration into `js/firebase-config.js`.
6. Create an admin user in Firebase Authentication.
7. Run the web folder with a local web server. Example:
   `python -m http.server 5500`
8. Open `http://localhost:5500`.

For production, deploy this folder using Firebase Hosting.
